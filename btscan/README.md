# BtScan

Small console app, part of the Bloopair audio extension.

Lists every discoverable Bluetooth device (not just controllers) found while you press the
SYNC button on the console. Results are shown on screen and saved to
`wiiu/bloopair/btscan.txt` on the SD card.

Requires the Bloopair loader (`30_bloopair.rpx`) built from this repository.
